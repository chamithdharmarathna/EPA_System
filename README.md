# Employee Performance Appraisal System (EPA System)

A web-based system for managing employee performance appraisals, projects, and institutions.

## Tech Stack

- **Frontend**: Streamlit
- **Backend**: FastAPI
- **Database**: SQLite
- **Language**: Python 3.11+

## Features

- Institution management with auto-generated IDs
- Employee performance tracking
- Project management
- Performance analytics and reporting
